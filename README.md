# HR AI Labs

An English landing page that brings together six AI-powered tools for recruitment and human resources.

## Projects

- **CV Reviewer AI** — Reviews resumes, identifies issues, and suggests improvements.
- **OfferX AI** — Helps create structured job offers.
- **Hirix AI** — Generates interview questions tailored to a candidate’s experience and skills.
- **JDX AI** — Creates clear job descriptions.
- **HR ReportX AI** — Helps prepare human resources reports and summaries.
- **Vetly AI** — Creates role-based assessments and evaluates candidate answers.

## File

- `index.html` — The English HR AI Labs landing page.

## Preview

Open `index.html` in a web browser.

## Deployment

This is a static HTML website. Import the repository into Vercel and deploy it. Vercel will serve `index.html` as the home page.
